# BLE App – Bluetooth Low Energy

## About the Project

BLE App is a Flutter-based application developed using the Flutter BLE package to explore and understand Bluetooth Low Energy (BLE) communication.

## Features

- **Nearby Device Discovery:** Scan for and discover nearby Bluetooth Low Energy devices.
- **Device Connectivity:** Connect to discovered BLE devices.
- **Bluetooth Communication:** Explore how BLE devices establish connections and exchange information.
- **Future File-Sharing Concept:** Designed with future possibilities in mind, including sharing images, audio, and other types of files between connected devices.

## Technologies Used

- Flutter
- Dart
- Flutter BLE Package
- Riverpod

## Project Purpose

This project is built for learning and exploring device-to-device communication.
